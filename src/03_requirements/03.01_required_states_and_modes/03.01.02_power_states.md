# Power States

The system shall support the following power states:

## STATE-PWR-001: Off/Unpowered State

**Definition**: The device has no power and is completely inactive.

**Characteristics**:

- No functionality available
- All volatile memory cleared
- Bluetooth radio inactive
- Display inactive
- Current consumption: 0 μA (excluding battery self-discharge)

**Entry conditions**:

- User performs power-off sequence
- Battery completely depleted
- Device not connected to power source

**Exit conditions**:

- User performs power-on sequence
- Battery inserted or charged above minimum threshold

## STATE-PWR-002: Sleep/Standby State

**Definition**: Low-power state maintaining essential functionality for quick wake.

**Characteristics**:

- Bluetooth LE connection maintained (if previously connected)
- Can wake on Bluetooth activity or user input
- Display inactive
- Encryption keys retained in secure storage
- Maximum current consumption: 50 μA average

**Entry conditions**:

- No user activity for configured timeout (default: 30 seconds)
- User explicitly activates sleep mode
- While in Active state

**Exit conditions**:

- User input detected (button press)
- Incoming message received via Bluetooth
- Bluetooth connection event

**Timing requirement**: Transition from Sleep to Active shall complete within 100 milliseconds.

## STATE-PWR-003: Active/Ready State

**Definition**: Fully operational state with all subsystems powered.

**Characteristics**:

- Display active
- Bluetooth LE active
- All cryptographic functions available
- User input processing enabled
- Full messaging capability available
- Maximum current consumption: 15 mA average

**Entry conditions**:

- System boot complete from Off state
- Wake from Sleep state
- User activity detected

**Exit conditions**:

- Sleep timeout expires without user activity
- User initiates power-off sequence
- Critical battery level reached
