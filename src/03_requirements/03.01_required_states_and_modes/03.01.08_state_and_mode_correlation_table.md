# State and Mode Correlation Table

The following table shows which modes are permitted in which states:

| State/Mode | Setup Mode | Normal Mode | Degraded Mode | Maintenance Mode |
|------------|------------|-------------|---------------|------------------|
| Off | Entry only | Exit only | No | No |
| Sleep | No | Yes | Yes | No |
| Active | Yes | Yes | Yes | Yes |
| Unpaired | Yes | Yes | No | Yes |
| Pairing | Yes | Yes | No | No |
| Paired | Required | Yes | Yes | Yes |
| Disconnected | Partial | Yes | Yes | Yes |
| Connected | Required | Yes | Transition out | Yes |
| Locked | Optional | Yes | Yes | No |
| Unlocked | Yes | Yes | Yes | Yes |
| Key Init Required | Yes | Transition only | No | Yes |
| Keys Established | Required | Yes | Yes | Yes |
| Key Rotation Pending | No | Yes | Yes | No |
