# Referenced documents

## Common Criteria Protection Profiles

The following Common Criteria Protection Profiles provide security requirements and evaluation criteria applicable to the ChatCard System:

### Primary Protection Profiles

1. **IoT Secure Communications Module Protection Profile**
   - Available at: [Common Criteria Portal](https://www.commoncriteriaportal.org/files/ppfiles/pp0110b_pdf.pdf)
   - Scope: Secure communication requirements for embedded/IoT devices
   - Relevance: Applies to ChatCard's secure communication architecture and Bluetooth LE transport layer

2. **PP-Module for Bluetooth**
   - Available at: [Common Criteria GitHub](https://commoncriteria.github.io/pp/bluetooth/bluetooth-release.html)
   - Scope: Bluetooth-specific security requirements including cryptographic key generation
   - Relevance: Applies to ChatCard's Bluetooth LE communication implementation

3. **Cryptographic Service Provider Protection Profile**
   - Available at: [Common Criteria Portal](https://www.commoncriteriaportal.org/files/ppfiles/pp0104b_pdf.pdf)
   - Scope: Requirements for cryptographic modules (hardware, software, firmware) and key management
   - Relevance: Applies to ChatCard's end-to-end encryption implementation and key storage

### Supporting Protection Profiles

1. **IoT Secure Element Protection Profile (IoT-SE-PP)**
   - Available at: [Common Criteria Portal](https://www.commoncriteriaportal.org/files/ppfiles/pp0109b_pdf.pdf)
   - Scope: Secure element requirements for IoT/embedded devices
   - Relevance: Applicable if ChatCard implements dedicated secure hardware for key storage

2. **Secure Messages Protection Profile v1.1**
   - Available at: [Common Criteria Portal](https://www.commoncriteriaportal.org/files/ppfiles/Secure%20Messages%20PP%20v.1.1.pdf)
   - Scope: Secure messaging system requirements
   - Relevance: Reference for secure messaging architecture and threat models

3. **Protection Profile for Application Software v1.1**
   - Date: 2014-11-05
   - Available at: [Common Criteria Portal](https://www.commoncriteriaportal.org/files/ppfiles/pp_app_v1.1.pdf)
   - Scope: General software security requirements
   - Relevance: Applies to companion mobile application development
