# System/Subsystem Specification (SSS)

This document follows DI-IPSC-81431A - System/Subsystem Specification.

## Purpose

The System/Subsystem Specification (SSS) specifies the requirements for a system or subsystem
and the methods to be used to ensure that each requirement has been met.

## Building

Run `sysdoc build` to generate the final document.

## Structure

- `src/01-scope/` - Identification, system overview, document overview
- `src/02-referenced_documents/` - Referenced documents
- `src/03-requirements/` - System requirements (capabilities, interfaces, data, etc.)
- `src/04-qualification_provisions/` - Qualification methods
- `src/05-requirements_traceability/` - Requirements traceability
- `src/06-notes/` - General information, acronyms, glossary
- `src/appendices/` - Appendices
